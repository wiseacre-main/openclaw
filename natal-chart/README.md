# natal-chart

Автоматическая система расчета натальных карт по месту и времени рождения с подробными расшифровками на русском языке.

Без внешних зависимостей в рантайме: собственный астрономический движок, встроенная база городов и таймзон, готовые тексты интерпретаций. Работает как библиотека TypeScript/JavaScript и как CLI.

## Возможности

- **Планеты:** Солнце, Луна, Меркурий — Плутон, Северный узел, Лилит (Черная Луна); долготы, знаки, ретроградность, скорость. Точность ~1–2 угловые минуты (алгоритм P. Schlyter), тропический зодиак.
- **Дома:** Асцендент, MC, куспиды по Плацидусу; цельнознаковая система — по выбору или автоматически на полярных широтах.
- **Аспекты:** мажорные и минорные, орбисы с поправкой на светила, сходящиеся/расходящиеся.
- **Место рождения:** встроенная база ~110 городов (Россия, СНГ, мир) с координатами и IANA-таймзонами; поиск по русским/английским названиям и алиасам («спб», «питер», «nyc»...). Либо явные координаты + таймзона.
- **Время:** перевод местного времени в UTC с учетом исторических правил (летнее время СССР, смены зон) через IANA tzdata.
- **Расшифровки:** авторские тексты для Солнца, Луны, Асцендента, Меркурия, Венеры и Марса в каждом знаке; дома, управитель карты, MC, узлы, Лилит, баланс стихий и крестов, все аспекты. Итог — подробный отчет в Markdown или структурированный JSON.

## Установка и запуск

Требуется Node.js 20+.

```bash
npm install
npm test        # 49 тестов, включая проверку по затмениям и соединениям планет
npm run build   # компиляция в dist/
```

### CLI

```bash
# по городу из встроенной базы
npm run cli -- --date 1990-05-15 --time 14:30 --place "Москва"

# по координатам и таймзоне
npm run cli -- --date 1985-11-02 --time 06:45 --lat 59.93 --lon 30.34 --tz Europe/Moscow

# JSON вместо текстового отчета, цельнознаковые дома
npm run cli -- --date 2001-01-01 --time 09:15 --place spb --houses whole-sign --json

# список поддерживаемых городов
npm run cli -- --list-cities
```

После `npm run build` доступен бинарь `natal-chart` (`node dist/cli.js ...`).

### Как библиотека

```ts
import { computeNatalChart, renderReport } from "natal-chart";

const chart = computeNatalChart({
  date: "1990-05-15",
  time: "14:30",
  place: "Москва", // или latitude/longitude/timezone
});

console.log(renderReport(chart)); // подробный отчет в Markdown
console.log(chart.planets);       // структурированные данные
```

## Структура проекта

```
src/
  astro/        # астрономия: эфемериды, дома, аспекты, юлианские даты
  geo/          # база городов, перевод местного времени в UTC
  interpret/    # тексты расшифровок и генератор отчета
  chart.ts      # оркестратор: вход -> структура карты
  format.ts     # знаки зодиака, форматирование градусов
  cli.ts        # командная строка
  index.ts      # публичный API
```

## Точность и ограничения

- Позиции планет: погрешность порядка 1–2′ — на порядки меньше ширины знака или дома; для астрологических задач этого достаточно. Диапазон дат: 1800–2100.
- Узел и Лилит — средние (mean), как в большинстве астрологических программ по умолчанию.
- На широтах выше ~66° система Плацидуса математически не определена — выполняется автоматический переход на цельнознаковые дома с пометкой в отчете.
- Расшифровки носят обзорный характер и не являются рекомендациями.

## Тесты

Движок проверяется по независимо известным астрономическим событиям: равноденствия и солнцестояния, солнечное затмение 11.08.1999, лунное затмение 21.01.2000, великое соединение Юпитера и Сатурна 21.12.2020, ретро-петли Меркурия (2021) и Марса (2020), исторические смещения таймзон (СССР, США).
